## 1. 拼多多「品牌管控」——标题里出现他牌名 = 直接驳回

- **表现**：提交能成功（成功页 `wait_audit=false`），审核后才驳，理由固定为
  「需提交来源凭证：①商标注册证 + 品牌方到开店主体的完整授权链路；②进货方为开店主体、
  写明品牌与进货时间的增值税发票」。
- **我们的实测样本**（2026-10-05 从店铺「已驳回」Tab 反查，5 条）：触发词 `克罗心`(Chrome Hearts) ×3、
  `奶芙芙` ×2。**`奈姿` 是 1688 供应商名，不是品牌触发词** —— 在售 231 件里 72 件带它且全部正常在售。
- **要点**：驳回是**上架之后**才发生的，所以"提交成功"不能当"上架成功"用（见 §6）。
- **处置**：`pdd_config.BRAND_WORDS` 是黑名单，`build_pdd_worklist_1688.py` 在生成队列时剔除；
  `sync_pdd_store.py` 每次核对会把驳回标题喂给 `candidate_brand_words()` 提名新词（提名≠拉黑，要人确认）。

## 2. 划线价 / 参考价 —— 我们现在是"无依据的被比较价格"

《明码标价和禁止价格欺诈规定》（市场监管总局令第 56 号，2022-07-01 施行，条款原文核用于 2026-10-05）：

- **第十六条**：进行价格比较的，被比较价格应真实准确；未标明被比较价格详细信息的，
  被比较价格**不得高于该经营者在同一经营场所价格比较前七日内的最低成交价格**。
- **第十七条**：经营者没有合理理由，不得在折价、减价前临时显著提高标示价格作为计算基准；
  **不得采用无依据或者无从比较的价格**作为折价、减价的计算基准或被比较价格。
- **第二十三条**：违反十六至二十条按《价格法》《反不正当竞争法》《电子商务法》《价格违法行为行政处罚规定》处罚。
- **执法热度**：2026 年多地市场监管部门就"虚假划线价"发过提醒告诫函/提示函并有处罚案例（2026-03~08 间多篇，
  报道口径为"虚构划线价最高罚 50 万元"）。
- **我们的现状**：`create_pdd_product.fill_step2` 里 `商品参考价 = 拼单价 × REF_PRICE_FACTOR(1.5)`，
  而这些新品**没有任何成交记录**（`order_info` 还是 2023 演示数据）→ 落在第十七条的"无依据/无从比较"上。
  拼多多该字段必填且必须大于最大单买价，所以不能留空。
- **收口方案（未执行，属经营决定）**：把 `REF_PRICE_FACTOR` 降到使参考价≈单买价+0.01，
  既满足平台字段约束又不主张折扣；代价是价签观感与转化。已在 `pdd_config` 注释里写清，改一个数即可。

## 3. 广告法极限词 / 化妆品功效词 —— 已扫，当前干净

- 规则库：已装技能 `global-ecommerce-intelligence/references/scripts/compliance-rules.json`
  （`absolute_terms` 最/第一/顶级/国家级/唯一/独家/绝对/100%/永久/彻底…；
  `medical_terms` 美白/祛斑/祛痘/抗衰老/医美/效果显著…；`platform_red_line.taobao` 官方/授权/旗舰店/正品保证/假一赔十）。
- **实测**（2026-10-05）：拿 `compliance-scan.mjs --platform taobao` 扫已上架 150 条 + 待铺 888 条标题
  （合计 30,807 字）→ **0 命中**。扫前先验过工具本身：喂一条含「全网最低价 / 100% / 官方正品 / 美白祛斑 / 第一名」
  的坏样本，正确报 6 处、risk=high。人工复核口径也一致：真实标题里只有「高级」23 条（风格描述，非极限词）、
  「持久」1 条。
- **为什么美甲类目要特别盯功效词**：穿戴甲属美甲饰品，写"美白/防过敏/医用胶"一类就是化妆品或医疗器械功效宣称，
  是平台与市监双重红线。目前队列里没有，但**换品类（护肤/化妆品）时这条会立刻变成高发区**。

## 5. 定价的真实口径（别再被常数表骗）

- 生效的是 **进价 × 5**（`PRICE_FACTOR_1688`），毛利率恒 79.4%。
- 那组"快递 3 / 费率 0.6% / 损耗 3% / **目标毛利 40%**"的成本倒推（`pdd_price_cost`）**只有单测在调**，
  改 `TARGET_MARGIN` 不会影响任何在售价。
- 40% 这个目标值本身**从未经营手人确认**。

## 6. 平台数据不能直接当经营结论

- **生意参谋快照混着一次性低质流量**：判据 `visitors>=100 AND bounce_rate>0.8 AND pay_byrs=0`
  （09-30 那次 14,966 访客里 14,365 来自 16 件这种商品，而全库正常商品平均 3.2 访客）。
  已落进首页趋势、KPI 与运营台"有流量没成交"。推导与逐条验证见
  `docs/superpowers/specs/2026-09-29-multiplatform-ingest-design.md` §34、§38。
- **recent7 是重叠窗口**：同一笔成交会在相邻 3 个快照里各出现一次，跨快照 `SUM` 必然重复计数。
- **提交成功 ≠ 审核通过**：判上架只能回在售清单核对（`sync_pdd_store.py`）。
