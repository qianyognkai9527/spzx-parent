# 淘宝归类 v2 合规填充器 — 设计文档

日期：2026-09-25
状态：已确认（用户批准设计与默认值）

## 背景

2026-09-20 后淘宝编辑页改版，三类新变化导致 v2 提交大面积失败（本轮 352 个处理中 ~85% 失败）：

1. **按类目新增必填字段**（页面自带错误态，零试提交即可读取）：
   - 家居服/睡衣：SKU 级「厚薄」（每行，批量入口=「去填写」）+ 属性级「面料」（材质成分，含量总和须=100%）
   - 长裤/牛仔短裤：SKU 级「是否加绒」
   - other：SKU 级「款式」
   - 连衣裙：属性级「上市年份季节」
   - 秋冬款：属性级「功能」「适用场景」「是否商场同款」（3 项）
2. **新增浮层拦截点击**：`#sku-preview-iframe`（SKU 预览浮窗）与 `#struct-error-board`（优化建议面板）覆盖页面，Playwright 点击被拦截（日志实证：一口价填写 Timeout）；旧 `ensure_extract_way` 的 JS `.click()` 对新 React 组件**无效**（点击后 checked 仍=false）→「提取方式 必填项未填」。
3. **「运费模板」新提示**（要求全网设置，暂按已有模板处理，发现缺失再人工）。

**独立问题（本任务不解决）**：`CHK_IMAGE_PC_PIC_STEAL` 主图盗图校验——家居服/睡衣在售池 160+ 个图片被版权标记，须换主图，属后续任务。

## 目标

1. v2 提交前自动填齐新必填字段（合规填充器），恢复非图片类商品的提交成功率。
2. 修复「提取方式」勾选（真点击 + 浮层清理）。
3. 提交失败仅剩 PIC_STEAL 的商品转 skipped（图片待换队列），避免无效重试。

## 用户已确认的默认值（写入真实在售商品）

| 字段 | 取值策略 |
|---|---|
| 厚薄 | 「常规」 |
| 是否加绒 | 标题含「加绒/绒」→是，否则「否」 |
| 款式 | 面板第一项 |
| 面料材质成分 | 「聚酯纤维 100%」（抖店同款商品线惯例值） |
| 上市年份季节 | 按当天日期推导（如 2026年秋季） |
| 是否商场同款 | 「否」 |
| 功能/适用场景 | 标题关键词推导，推不出用默认第一项 |

## 设计

### 1. 新模块 `automation/sourcing/compliance_filler.py`

```
clear_overlays(page)      隐藏 #sku-preview-iframe 挂载容器(.sku-preview-drag-wrapper)
                          与 #struct-error-board（display:none；纯预览/诊断 UI，非表单数据）
fill_extract_way(page)    浮层清理后 Playwright 真点「使用物流配送」label（校验 input.checked 翻转为准）
detect_gaps(page)         读 body 错误态文本（"X：Y不能为空"/"必填项未填"上下文），
                          归一化为字段名列表 + 位置（sku/prop/extract）
fill_gaps(page, gaps, title)  按 FILL_RULES 逐项填充：
                          - SKU 级 → 点「去填写」批量面板，全行设值后确认
                          - 属性级 → 属性区对应控件（select/多选/材质成分组合）
FILL_RULES                字段名 → 取值策略（上表；title 派生项由 v2 传入商品标题）
```

### 2. v2 集成点（assign_shop_category_v2.py）

- `process_one` 在 `wait_edit_ready` 后**先 `clear_overlays`**（调价点击也被浮窗拦，须在 update_prices 之前）。
- 归类完成后、删视频/提交前：`detect_gaps → fill_gaps → re-detect`（残留非空→fail 带明细节流）。
- 主循环 fail 分支：若错误**仅含 PIC_STEAL**（无必填/规格字样）→ 该 itemId 从 failed 移入 skipped（原因=PIC_STEAL 待换图）。

### 3. 探路验收（6 个已失败样本）

## 不做的事

- 不自动创建运费模板（现有模板缺失时留人工）。
- 美甲池维持 skipped 不动。
- 不改八类目规则与调价规则。
